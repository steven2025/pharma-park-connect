# 医药成果协作网络

面向医药科技成果转化场景的前端产品验证版。以具体的人为核心，通过人物专业主页、项目库、双向搜索和合作申请，验证园区可信协作网络的产品模式。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

构建结果位于 `dist`，可直接发布到 GitHub Pages。Vite 已使用相对资源路径配置，适用于仓库子路径部署。

## 验证范围

- 人物搜索、筛选和专业主页
- 项目搜索、筛选和项目详情
- 人物与项目双向关联
- 分步入驻和项目发布表单
- 合作申请及处理流程
- 桌面与移动端响应式布局

页面中的人物、机构、项目和业务数据均为虚构演示数据。
